# Cycle

Cycle is a scientific calculator built in Rust with libAdwaita. I created it because I study physics and have been looking for a calculator that allows me to easily use physical constants. None of the sites/programs I tried did exactly what I needed, so I made my own calculator.

#### What does the name mean?
"Cycle" sounds a lot like "Sci-Cal", which is short for scientific calculator.

### AI
Since AI is a controversial coding tool, I'll explain how it was used in the development of Cycle. The code is NOT AI-generated, except for a few lines in `about.rs`. The inclusion of the icon was done with AI-generated code. Apart from this, the code is handwritten. I did, however, use AI in debugging. I put error codes into an LLM and looked at explanations of what was wrong. From there, I often went to documentation to understand what the proposed solution would do. Never did I copy-paste the LLM's solution, because to me that's no fun.
