# Cycle

Cycle is a scientific calculator built in Rust with libAdwaita. I created it because I study physics. I had been looking for a calculator that allowed me to easily use physical constants. None of the sites/programs I tried did exactly what I needed, so I made my own calculator.

### What does the name mean?
"Cycle" sounds a lot like "Sci-Cal", which is short for scientific calculator.
